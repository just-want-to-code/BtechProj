# Welcome to our Btech Project

Our goal is to do object segmentation using graph cuts and also incorporating texture information using various texture feature extraction methods.


# Files
- [Graph cuts](https://github.com/just-want-to-code/BtechProj/blob/main/graph_cuts_og.ipynb)- Object segmentation using graph cut based active contours
- [GLCM method](https://github.com/just-want-to-code/BtechProj/blob/main/graph_cuts_glcm.ipynb)- Extracting texture features using Gray Level Co-occurrence Matrices
- [Gabor Filter](https://github.com/just-want-to-code/BtechProj/blob/main/graph_cuts_gaborfilters.ipynb)- Extracting texture features using Gabor filters
- [Tamura](https://github.com/just-want-to-code/BtechProj/blob/main/graph_cuts_tamura.ipynb)- Extracting the tamura features like contrast and correlation and using them in graph cuts
- [Structure tensors](https://github.com/just-want-to-code/BtechProj/blob/main/graph_cuts_structure_tensors.ipynb)- Extracting the texture features using structure tensors

We have used these various texture extraction methods and used these in our graph cut algorithm to do object segmentation.
